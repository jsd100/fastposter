# 内置字体

内置字体由 `manifest.json` 声明，启动核心服务时按稳定 asset ID 幂等补齐。字体文件仅在文档使用或用户预览对应家族时加载。

本轮新增中文字体：

| 字体家族 | 编辑器名称 | 样式 |
| --- | --- | --- |
| Ma Shan Zheng | 马善政毛笔楷书 | 毛笔楷书 |
| Long Cang | 龙藏手书 | 手写 |
| ZCOOL QingKe HuangYou | 站酷庆科黄油体 | 标题 |
| Liu Jian Mao Cao | 刘建毛草 | 草书 |

四款均取自 Google Fonts 官方仓库 commit `406197b91ff39a93061c2c2eeaee67ddf2ae1f0d`。具体来源 URL 和 SHA-256 存于清单，每款附带原始 SIL Open Font License 文本。总计 10 个家族、15 个字面。

Inter 为西文字体，不包含中文字形。编辑器在目标文本含中日韩字符或全角标点时禁用西文选项；选中英文或空光标时仍可选择。服务端保留实际字形覆盖校验，上传字体与非常用字符仍以该校验为准。

新增字体无需数据库迁移，重启核心服务后即可出现在目录中；原有字体版本和作品引用保持不变。
