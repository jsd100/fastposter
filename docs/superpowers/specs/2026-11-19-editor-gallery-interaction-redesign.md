# FastPoster 渐变与卡片交互重设计

## 范围和视觉基准

覆盖共享编辑器的文字颜色面板、用户站创建和替换背景的背景库、`/projects` 的回收站视图、`/admin/backgrounds` 的素材卡片。用户希望第一眼能看清渐变的角度和颜色，背景图可以从图片本身打开大图，回收站按钮与卡片尺寸协调，后台三枚按钮的边框统一。

沿用仓库锁定的 Ant Design 6.7.0、中文默认主题和系统字体。使用主题的背景、文字、边框、主色和危险色变量。标题、尺寸和更新时间分层。把视觉强调留给画布、背景图、当前选区和最终确认。卡片保留作品列表已有的 hover 和 focus-within 高亮。

本批交互限于上述界面。保存及导出沿用 v1/v2 协议、既有 API、权限、版本校验与撤销事务。后台字体页共用的卡片在本批保持现有操作样式。

## 共享文字颜色面板

### 现状

`TextPanel.tsx` 通过独立的「渐变填充」下拉创建渐变，后续调节要再打开「文字颜色」色块。`TextColorField.tsx` 用内联绝对定位的容器承载渐变面板，类型和预设是浏览器原生下拉，色标位置是原生数字框，按钮、取色器与角度滑块已经使用 antd。缺少即时的渐变样张，每个色标都占一行。角度滑块能表达数值，无法直接表达方向。

### 设计

- 面板行使用「文字颜色」标题和带色块、类型及展开箭头的触发器。纯色状态给出可见的「纯色 / 渐变」字样，混合选区继续显示「混合」。一个入口直接打开颜色面板。顶部使用 antd `Segmented` 切换「纯色 / 线性渐变 / 径向渐变」。已有「预设文字颜色」快捷项保留在纯色或混合状态。
- 桌面使用受控 antd `Popover`，优先朝画布侧展开并支持贴边调整，窄屏编辑器断点 ≤680px 时使用仓库已有的 antd 底部抽屉包装。复用同一份面板内容；最大高度受可视区约束，内部可以滚动，完成按钮可达。紧凑布局遵循现有字号和间距。首先呈现字样预览，其次是方向与色标，预设置于色标之后。
- 线性使用可点、可拖的时钟式方向盘，显示四个基准方向。12 点是 0°，3 点是 90°，顺时针增长，和 CSS `linear-gradient` 一致。方向盘旁使用 antd `InputNumber` 显示或输入角度，单位是 °。方向盘支持焦点、方向键 1°、Shift 加方向键 15°，鼠标和触屏共用同一角度计算。跨越顶部时环绕。已有小数角度按实际精度回显；整数手势更新使用 1° 步长。清空数值为输入草稿，失焦恢复最近有效角度。
- 径向将方向盘替换为可点、可拖的圆心位置板，右侧有 X 和 Y 百分比 `InputNumber`。左上为 0/0、右下为 100/100。键盘通过 X/Y 数字输入能完成同样的设置。拖动方向盘、移动圆心、修改色标时，字样预览和画布同步变化。字样预览使用共享渲染器读取颜色和方向，实际海报样张仍是画布。
- 渐变条按色标位置显示颜色，在一个位置只能读到一组颜色的歧义由色标列表或键盘焦点解决。下方只显示当前选中色标的位置、颜色和删除动作。颜色使用 antd `ColorPicker`，位置使用 `InputNumber`，其余动作用 `Button`。相邻色标可重合，保留现有硬色边语义。同位置色标各自可通过 Tab 或色标序号选中。限制为 2–8 个色标。新增色标放在现有色标跨度最大的间隔中点并选中，用该位置的插值颜色初始化。同位置时用第一组间隔的颜色。拖拽与数字录入约束在相邻色标范围内，避免拖动中更换选中的色标。纯色使用同一面板内的取色控件或颜色字段，保留 HEX 与透明度的编辑入口。
- 类型切换保留颜色与位置。线性、径向各自的角度或圆心参数在同次编辑中记忆，首次使用默认 90° 或 50% / 50%。从已知纯色首次转换时，0% 色标继承当前颜色，100% 色标按明度向白或黑混合 35%，保留相同透明度。混合选区使用现有暖阳的两种颜色。由渐变切回纯色带入第一个色标，纯色再切回渐变恢复同次会话中最近一组色标，其中第一个色标继承期间修改过的纯色。现有渐变预设显示为带名称的预览色片，选择时应用预设的完整类型、参数与颜色。原有预设名称及定义沿用。
- 从首次实际改值到「完成」、点外部或切换选区关闭是一笔已有控制事务，画布即时预览。Esc 取消本次颜色编辑，子取色器打开时第一下 Esc 先关子层。门户里的菜单与输入纳入现有弹层键盘保护，避免吞 Tab 或误触画布快捷键。关闭后恢复到触发器；用户点击另一个可交互控件时保留点击目标的焦点。编辑选区时继续使用编辑器已有的选区恢复和范围 ID 分配，避免颜色应用到错误的文字。类型转换和第一次保存后的撤销用现有 v2 单调保护。

设计取舍由本方案提出。标准输入和弹层使用 antd。方向盘、圆心板、渐变色标轨道负责可视化操作，单独做轻量可访问控件。Ant Design 的渐变取色模式用于它自身的颜色编辑语义，FastPoster 的线性角度、径向中心、稳定色标和事务继续走文档模型。

## 用户站背景库

当前可见缩略图嵌在「选择/选用」按钮里，大图由下方独立按钮和一个隐藏的 `Image` 触发。两个操作抢占卡片视觉空间。「不同尺寸会调整……」的提示在创建场景也出现。

- 每项是一张卡片，Ant Design `Image` 作为可见封面。完整缩略图用 `object-fit: contain` 保持比例，封面槽等高。优先让图更大、减少外层空白。标题单行截断，支持看完整名称，尺寸用次级文字。搜索、分类和分页保留。
- 用 `Image.preview.cover` 在图片 hover 或键盘焦点时显示放大图标，触屏常显小图标。点击、轻点或以 Enter / Space 激活图片即可打开全屏大图。缩略图用 `previewUrl`，打开大图才请求对应素材版本的 `url`。移除卡片下方整行「放大预览」。原图缺失或失败留在大图层提示，关闭仍可用。
- 图片触发预览，卡片信息区的紧凑按钮选择或选用。创建时显示「选择 / 已选择」，所选卡片带边框，继续由「用此背景创建」完成，保留原有重新核对资源版本的步骤。替换时点「选用」直接沿用现有替换与异尺寸确认。创建页移除尺寸调整提示，替换页才显示简短提示。保留 `选择 <标题>` 和 `选用 <标题>` 的无障碍名称。
- 关闭大图只收起当前层。Esc 或关闭按钮返回原图片焦点，原项已变化时返回搜索框。查看大图和关闭均不选择、创建或替换作品。无 hover 设备可直接点开；图片和选用操作分别可聚焦。

## 回收站

当前 `ProjectList.tsx` 把「恢复」「彻底删除」放在信息下方，`styles.css` 对两者无条件设 44px 高度，且后者使用实心红色。窄卡片重排时形成两个抢眼的独立块。

- 用卡片底部单行操作区，左边是默认描边「恢复」，右边是危险描边「彻底删除」。桌面使用 antd 默认按钮高度和紧凑内边距。最终删除确认保留实心危险按钮及既有确认内容、加载和错误反馈。
- 窄屏操作区为可收缩布局，两个按钮优先同排。空间不足允许换行，由卡片宽度决定，按钮不超出边界。触屏使用至少 44px 的可点区域，桌面无需继承这项高度。标题和元数据继续占独立的行。长标题截断，焦点与 hover 使用共享高亮。

## 管理站背景库

`Resources.tsx` 的「编辑」是 link 样式，「下架」是普通描边，「发布」是实心主按钮，「删除」是危险描边。同组操作缺少一致高度和视觉分量。

- 「编辑」「发布 / 下架」「删除」使用三个等高的 antd 描边按钮，前两个为默认边框，删除是危险描边。已发布状态由图片右上角的状态 Tag 表达。三枚按钮优先同排，窄卡片时自然换行，间距一致。
- 图像、标题、尺寸、版本、发布状态在同一张卡片内保持稳定顺序。发布冲突仍走已有确认重试，删除仍走已有确认。后台背景封面维持展示用途，本次用户站图片放大交互覆盖创建与替换两处入口。

## 验收

1. 在线性和径向之间切换、用方向盘和键盘调角、拖动圆心、编辑透明色、添加和删除色标、修改同位置色标。颜色与角度立即在画布可见。保存重开、撤销、选区局部修改、旧纯色文档以及 PNG 导出回归通过。
2. 验证从纯色直接进入到渐变，Esc 分层关闭，数字草稿不误写为零，触屏拖动有效，门户弹层不会触发画布快捷键。弹层在真实内容和五档视口下均可操作。
3. 验证创建与替换路径的鼠标、键盘和触屏打开大图，确认原图延迟加载、大图错误反馈、关闭焦点恢复和选择状态隔离。创建继续做资源版本核对，异尺寸替换继续弹确认。
4. 用长标题、缺图、不同发布状态、窄卡和宽卡验证卡片对齐与按钮大小。回收站和后台的取消、确认、失败、重试仍按原流程运行。视觉验收使用 1440、1024、768、390、320px 五档，检查无横向滚动且操作可达。
