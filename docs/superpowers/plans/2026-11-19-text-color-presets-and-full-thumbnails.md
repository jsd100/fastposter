# 文字颜色预设与完整背景缩略图

**目标** 将预设归入颜色弹层，并完整展示用户站背景缩略图。

**约束** 沿用 Ant Design 6.7.0、共享 Select、颜色事务、既有渐变协议及背景选择与原图预览行为。

## 文字颜色

- [x] 为纯色下拉迁入、搜索、渐变类型隔离、预设回显和分层 Esc 补浏览器回归。
- [x] 共享 Select 加上按需分组、搜索、闭合值预览和受控下拉能力。现有调用沿用原配置。
- [x] 将 116 个纯色预设全量按现有色系及精选系列迁入文字颜色弹层。添加线性与径向各 12 个预设，同类型应用完整参数，手动编辑离开预设时回显「自定义」。
- [x] 下拉放在实时预览与精细控件之间。选择沿用颜色事务，Esc 逐层关闭，桌面和手机都保留键盘和焦点行为。
