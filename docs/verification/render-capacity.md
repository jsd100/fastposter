# 本机渲染路线验证

日期：2026-10-30。此记录验证共享 DOM 排版、透明文字层、Go 合成与 PNG 编码；不代表完整作品保存/导出任务系统已交付。

## 环境

- macOS arm64，Go 1.27.2，Chrome 156.0.8078.48。
- chromedp v0.21.0 / cdproto v0.157.8；Node 24.21.0，React 19.3.1，Vite 8.3.5。
- 字体：Google Fonts 官方仓库的 Noto Sans SC 和 Inter 可变 TTF。授权和内容散列见 `assets/fonts/`。
- 单次浏览器渲染、DPR=1；本机回环资源服务，字体无外部依赖。

## 已执行的验证

`FASTPOSTER_RENDER_TEST=1 FASTPOSTER_CAPACITY_TEST=1 go test ./server/tests/integration -run TestRender -count=1 -v`

| 场景 | 结果 |
| --- | --- |
| 中文混合字号与局部双色 | 正确布局，最终像素中包含两种指定文字颜色 |
| 同一块 Noto Sans SC / Inter 字体混排 | 实际字体加载完成后渲染通过 |
| 4000×6000 透明文字层 | 解码尺寸精确一致，约 0.79 秒 |
| 8192×4800 渲染、完整尺寸背景合成、PNG 编码 | 解码头尺寸一致，末端未覆盖背景像素保留，约 1.68 秒 |
| 4800×8192 渲染、完整尺寸背景合成、PNG 编码 | 同上，约 1.67 秒 |
| 固定字体/浏览器重复渲染 | PNG 内容散列一致 |
| 无文字的画布 | 全画布 alpha=0 |
| 缺失字体版本 / 缺失实际字重 | 明确失败，不使用替代字体或合成字重 |
| x=0.25、width=1199.75 的合法边缘文字块 | 保留小数宽度，不误报溢出 |

上述测试批次耗时 8.82 秒（含测试程序编译/启动等开销）。`/usr/bin/time -l` 报告 maximum resident set size 为 813,711,360 字节（约 776 MiB）；这是该命令的进程级统计，不是生产环境整个 worker/Chrome 进程树的并发峰值承诺。生产运行仍保持并发 1，并在完整任务系统完成后复测。

## 像素回归

`go test ./server/internal/exports -v` 验证未覆盖的普通/半透明/全透明背景像素保持 RGBA，透明层尺寸不符时失败。开发时发现并已通过失败测试后修复：

- `draw.Over` 会归一化 alpha=0 背景的隐藏 RGB；现在跳过文字层中 alpha=0 的像素。
- CDProto 的 RGBA alpha 字段会在零值时省略，而 Chrome 默认 alpha=1；内部命令显式序列化 `a:0`。
- 整数 DOM offsetWidth 会把合法小数宽度误报越界；布局测量改用 DOMRect 并还原视图缩放。
- 字体资源 ID 的连字符与下划线不能映射到相同 CSS family；现在保留原 ID。
