# Ant Design 默认样式回退验收

用户站、管理站和共享编辑器采用仓库固定的 Ant Design 6.7.0 默认主题。登录表单、页面外壳、资源卡片、弹窗、通知和编辑控件使用 antd 组件。项目保留页面网格、响应式断点、画布交互和手机触控尺寸所需的样式。

- `pnpm verify` 通过契约漂移检查、类型检查、219 项单元测试和工作区构建。
- 使用 Vite 的 `--manifest --sourcemap` 构建后运行 `tools/check-entry-boundary.mjs`，web、admin、renderer 三个入口均通过。
- 启用 `FP_UI_BASELINE=1` 运行 `tests/e2e/ui-baseline.spec.ts`，10 项通过，覆盖 1440×1000、1024×768、768×1024、390×844、320×700。截图包含登录、作品、资源选择、编辑器和后台表单。
- 62 项浏览器验收及定向回归用例通过，覆盖 antd 默认按钮与焦点、手机属性面板及字体菜单、后台导航及密码重置、加载与通知、五级文案目录和 PNG 导出。各 spec 使用独立临时测试栈，后台密码重置末两项及离线保存用例在独立测试栈复验通过。

## 页面布局复核

- 作品卡片保留完整海报预览，统一标题、尺寸和更新时间的字号与间距。模板卡片限制预览高度，新建海报弹窗宽 376px，窄屏按视口收缩。
- 编辑器四个属性分组改用 antd Segmented，字号保留整行输入空间，位置单位进入输入框后缀。后台筛选限制搜索与分类控件宽度，用户名和记录 ID 分行，背景、字体与模板卡片共用固定高度预览区。
- `pnpm verify` 再次通过，包含 219 项单元测试及构建。三个前端入口通过构建边界检查。
- 五档截图与布局用例 10 项通过，覆盖后台搜索宽度、模板缩略图高度、新建弹窗宽度。另有 27 项定向用例通过，覆盖属性分组键盘切换、跨断点草稿、手机编辑、后台资源和 PNG 导出。跨断点草稿用例遇到 Vite 热更新重载，独立重跑通过。

## 后台操作按钮

- 文案分类树使用 antd 图标按钮，添加和编辑图标在常态下可见。图标尺寸回归在修复前失败，修复后通过。
- 后台列表区分主操作、普通操作、链接和危险操作。模板卡片保留编辑、预览和更多，菜单包含发布或下架、导出和删除。
- `pnpm verify` 通过，219 项单元测试通过。10 项定向浏览器用例通过，覆盖五级分类、发布冲突、模板包导出、删除后分页、后台记录和密码重置。截图用例验证更多菜单可用 Enter 打开、Escape 关闭。
